# PicaPhoto

基于 Python + Tkinter 的可视化媒体文件管理工具：图片/视频分类整理、相册管理、批量移动、缩略图预览、撤销操作，支持亮色/暗色双主题与快捷键。

移动版 Android Studio 源码位于 `android/`，网页资源位于 `mobile/`；当前移动版为 v2.0.1（versionCode 51）。

## ✨ 功能亮点
- 图片 / 视频一键扫描、分类筛选（全部 / 照片 / 视频）
- 单图模式：方向键 / 滚轮快速切换，支持旋转、镜像预览
- 预览网格模式：圆角缩略图、多选、批量移动到相册
- 相册管理：新建 / 重排 / 删除，数字快捷键快速归类
- 撤销上一步移动（Ctrl+Z）
- 自动刷新目录、进度 / 相册 / 主题自动保存
- 微信/飞书风格界面：左侧导航、分组设置、绿色胶囊开关
- 高分屏适配：DPI 感知 + 界面按系统缩放自动放大，文字不发虚
- 超大图片兼容：放开 PIL 像素上限，缩略图加载省内存
- 深色 / 浅色双主题

## 🚀 使用（源码运行）
需要 Python 3.7+ 与依赖：
```bash
pip install pillow
# 如需视频预览：pip install opencv-python
# Linux/Ubuntu：sudo apt-get install python3-tk
python PicaPhoto.py
```

## 📦 Windows 一键打包（可选）
运行 `Pack.bat` 即可用 PyInstaller 生成单文件 EXE（含 OpenCV 视频支持）。

## ⌨️ 快捷键
| 按键 | 功能 |
|------|------|
| ← / → | 单图模式切换上一张 / 下一张 |
| Tab | 切换单图 / 预览网格模式 |
| Ctrl+A | 预览模式全选 |
| Ctrl+Z | 撤销上一次移动 |
| Esc | 退出预览 / 关闭弹窗 |
| R / F | 旋转 / 镜像翻转 |
| 1–9 | 快速移动到对应序号相册 |

## 📌 使用流程
1. 点击「选择目录」指定媒体文件夹，自动扫描图片与视频
2. 单图模式逐张浏览，滚轮 / 方向键切换
3. 按 Tab 进入预览网格，多选后批量移动
4. 底部「+ 新建相册」创建相册，用数字键快速归类
5. 关闭程序自动保存进度、相册与主题配置
