# PicaPhoto

基于 Python + Tkinter 的可视化媒体文件管理工具：图片/视频分类整理、相册管理、批量移动、缩略图预览、撤销操作，支持亮色/暗色双主题与快捷键。

移动版 Android Studio 源码位于 `android/`，网页资源位于 `mobile/`；当前移动版为 v2.0.11（versionCode 61）。

v2.0.11 增加原图长按预览与双指缩放，批量移动改为逐张撤销，手机照片删除改进 Android 系统回收站，并统一大小图相册栏；移动后多次刷新相册封面和数量。

v2.0.10 强制在每次打开相册时以 MediaStore 完整结果刷新旧缓存；已有相册按真实相册 ID/路径移入；损坏缩略图会删除并重建，并降低缩略图解码尺寸与重复超时。

v2.0.9 修复部分设备完整照片查询提前结束导致首页与整理页张数不一致，并为缩略图加载增加超时释放、高优先级重试和失效缓存再生成。

v2.0.8 将整理排序和媒体筛选从设置移到照片整理页顶部，并统一小图多选与大图整理的相册胶囊样式。

v2.0.7 修复“未整理”只显示首页数据的问题：进入后会在后台补齐完整队列，同时修复年/月/日分隔标题被压成 30px 方块而裁切的问题。

v2.0.6 在首页“未整理”卡片直接显示当前张数，并会随隐藏相册和回收站状态更新。

v2.0.5 修复 vivo/iQOO 开启系统级相册管理权限后仍重复询问的判定，并修复大图移动跳片、撤销不回到原照片、隐藏相册未完整计入未整理等问题；新增按时间/大小排序和照片/视频筛选。

## ✨ 功能亮点
- 图片 / 视频一键扫描、分类筛选（全部 / 照片 / 视频）
- 单图模式：方向键 / 滚轮快速切换，支持旋转、镜像预览
- 预览网格模式：圆角缩略图、多选、批量移动到相册
- 相册管理：新建 / 重排 / 删除，数字快捷键快速归类
- 撤销上一步移动（Ctrl+Z）
- 自动刷新目录、进度 / 相册 / 主题自动保存
- 微信/飞书风格界面：左侧导航、分组设置、绿色胶囊开关
- 高分屏适配：DPI 感知 + 界面按系统缩放自动放大，文字不发虚
- 超大图片兼容：放开 PIL 像素上限，缩略图加载省内存
- 深色 / 浅色双主题

## 🚀 使用（源码运行）
需要 Python 3.7+ 与依赖：
```bash
pip install pillow
# 如需视频预览：pip install opencv-python
# Linux/Ubuntu：sudo apt-get install python3-tk
python PicaPhoto.py
```

## 📦 Windows 一键打包（可选）
运行 `Pack.bat` 即可用 PyInstaller 生成单文件 EXE（含 OpenCV 视频支持）。

## ⌨️ 快捷键
| 按键 | 功能 |
|------|------|
| ← / → | 单图模式切换上一张 / 下一张 |
| Tab | 切换单图 / 预览网格模式 |
| Ctrl+A | 预览模式全选 |
| Ctrl+Z | 撤销上一次移动 |
| Esc | 退出预览 / 关闭弹窗 |
| R / F | 旋转 / 镜像翻转 |
| 1–9 | 快速移动到对应序号相册 |

## 📌 使用流程
1. 点击「选择目录」指定媒体文件夹，自动扫描图片与视频
2. 单图模式逐张浏览，滚轮 / 方向键切换
3. 按 Tab 进入预览网格，多选后批量移动
4. 底部「+ 新建相册」创建相册，用数字键快速归类
5. 关闭程序自动保存进度、相册与主题配置
