# PicaPhoto 移动版（PWA）

面向手机的全新版本，针对高刷（120Hz）与高分屏（devicePixelRatio）优化，操作逻辑按手机重新设计，不是桌面版简单移植。

## 📲 安装到手机
1. 把本文件夹部署到任意静态服务器（或本机用 `python -m http.server` 起服务）
2. 手机浏览器打开 `index.html`
3. Android：Chrome 菜单 →「添加到主屏幕」；iOS：Safari 分享 →「添加到主屏幕」
4. 之后像普通 App 一样从桌面图标打开，可离线使用

## 📱 移动端操作逻辑（全新设计）
- **底部导航**：相册 / 照片 / 设置
- **添加照片**：右下角 ＋ 按钮调起系统相册多选
- **浏览**：全屏查看器，左右滑动切换、点击隐藏工具栏、视频内嵌播放
- **多选整理**：长按照片进入多选 → 点选 → 底部悬浮条「移动到相册 / 移除」
- **相册**：卡片网格，长按相册可重命名/删除，点按进入
- **深色模式**：设置页绿色胶囊开关，跟随系统/手动切换
- 数据保存在本机 IndexedDB，不影响手机原图

## 🖥️ 高刷 / 高分屏适配
- 界面动画仅用 transform/opacity（GPU 合成），120Hz 下流畅
- 图片自适应 devicePixelRatio，高分屏清晰
- 适配刘海屏安全区（safe-area），全面屏正常显示
