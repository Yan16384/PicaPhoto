# PicaPhoto 移动版（APK / PWA）

手机图片整理：相册分类、滑动浏览、批量移动、回收站、自动更新。适配高刷（120Hz）、高分辨率、全面屏（刘海/水滴/挖孔）。

## 📲 安装
1. 下载 **PicaPhoto_v2.0.4.apk** 直接安装（自动更新可用）
2. 或部署本目录到静态服务器，手机浏览器打开 index.html 作为 PWA 使用

## 📱 操作逻辑
- **底部导航**：整理 / 我的（统计 + 日历 + 设置）
- **首页**：手机相册网格（横排4个），下拉刷新，长按相册管理，＋新建相册（系统层面）
- **照片网格**：3 列分块懒加载；**横向滑动进入管理模式**（点选/滑选，左下角数字标号），底部相册一键移入/删除
- **大图整理**：单张卡片上滑向右上角收缩后打开相册选择（设定默认相册时直接归类）；右上角移入回收站；下滑收藏/保留；可标记已审阅
- **待筛选队列**：首页入口会隐藏已审阅照片，可从上次相册继续；移动、收藏和手动标记都会记录已审阅状态
- **撤销**：移动与回收站均支持连续撤销；大图右上角提供紧凑撤销按钮
- **系统相册移动**：移动前显示 Android 系统写入授权；成功后可在提示中点「撤销」恢复原相册
- **相册访问权限**：Android 12+ 可一次开启媒体管理特殊访问；Android 11 对当前整理队列批量授权，避免逐张询问
- **回收站**：App 内软删除（系统文件不动），支持恢复 / 彻底删除 / 全部恢复 / 清空（清空才真正删除系统文件，走系统确认）
- **我的**：累计/今日整理、累计回收/恢复、收藏数、按天日历图、存储空间、清理缓存、清理存储（保留统计与收藏）
- **设置**：外观主题、待筛选排序、默认归类相册、清除已审阅记录、检查更新、忽略版本
- **自动更新**：启动检测新版本，仅「忽略本版本 / 更新」两个操作

## 🖥️ 全面屏 / 高刷适配
- 状态栏/导航栏自动按主题变色，内容延伸至挖孔区（CSS safe-area 避让）
- 动画仅用 transform/opacity（GPU 合成），120Hz 流畅；图片走系统缩略图 + 分块渲染 + 预加载
- 版本 v2.0.4（versionCode 54）
